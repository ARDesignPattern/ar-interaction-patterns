Technology Overview

This module provides the technical implementation resources for the HMD-AR Interaction Design Pattern Language, developed through doctoral research on augmented reality experiences in museums and cultural heritage.

The pattern language consists of 3 Category-Level Patterns and 9 Application-Level Patterns. The Category-Level Patterns provide conceptual design guidance, while the Application-Level Patterns are the focus of the Unity-based implementation toolkit.

Each implementation is designed to provide reusable Unity prefabs, scripts, and supporting assets, distributed as individual .unitypackage files. The toolkit aims to support modularity, parameterization, and the combination of multiple interaction patterns within a single AR application.

The original implementations primarily target Microsoft HoloLens 2 and were developed using Unity 2020.3.25f1, MRTK 2.8.3, and URP 10.7.0, together with compatible OpenXR components. Compatibility with other Unity versions and XR platforms has not yet been established.

Existing implementations are being reviewed for independent installation, dependency management, and cross-package compatibility. Individual packages and documentation will be updated progressively as validation proceeds.

To get started, visit the GitHub repository for environment requirements, installation instructions, and implementation documentation. Available Unity packages can be downloaded from GitHub Releases and imported into compatible Unity projects.
