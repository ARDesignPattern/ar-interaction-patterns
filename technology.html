HMD-AR INTERACTION DESIGN PATTERN LANGUAGE

Unity Toolkit

Reusable Unity implementations of interaction design patterns for head-mounted augmented reality in museums and cultural heritage.

Developed through doctoral research, this toolkit translates selected Application-Level Design Patterns into reusable Unity prefabs, scripts, and supporting assets. It includes five pattern implementations and one supporting authoring module.

How to Use the Toolkit

The toolkit is intended for Author Users and developers with basic Unity experience. Follow these steps to integrate an implementation into your own HMD-AR application.

  1. Set up the environment. Prepare a compatible Unity project using Unity 2020.3.25f1, MRTK 2.8.3, and URP 10.7.0. Consult the GitHub repository for project configuration and dependencies.
  2. Choose and import an implementation. Select a module from the library, download its UnityPackage from GitHub Releases, and import it into your Unity project.
  3. Configure the Prefab. Open the included example scene or add the relevant prefab to your own scene. Replace demonstration content and connect the required GameObject references and interaction events.
  4. Test and adapt. Run the scene, verify the interaction behavior, and adjust parameters and spatial placement to match your exhibition requirements.

The research pattern language contains 3 Category-Level Patterns and 9 Application-Level Patterns. This toolkit provides implementations of a selected subset. Application-specific content, spatial configuration, and final integration remain the responsibility of the Author User. Compatibility beyond the documented development environment has not been established.
